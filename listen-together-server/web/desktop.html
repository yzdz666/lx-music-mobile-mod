1.1.4

先说清楚

这是非官方二改版，与洛雪官方无关联。安装包没有购买代码签名证书，Windows 首次运行可能提示「已保护你的电脑」，点「更多信息」再点「仍要运行」就行。介意的话可以先用绿色版，解压直接运行。

桌面版和手机版一样不内置音源。装好后到「设置 → 基本设置 → 音乐 API → 导入」导入音源脚本，播放和下载才会真正按所选音质取链。

从 1.1.2 或更早版本升级，直接覆盖安装即可，歌单与设置都保留。1.1.1 及更早的 Windows 版若出现「装完只有进程、没有窗口」，装 1.1.2 或本版都能解决。

功能一览

对照手机版 1.22.37

全 11 档音质

播放 8 档、下载 11 档。设置里能选、能按所选档位向音源发起请求；声明不全或请求失败时自动逐档回退，不提前降级。下载弹窗带「最佳音质」，一键选歌曲最高可用档。

128k 192k 320k flac flac24bit hires atmos atmos_plus master ape wav

我的音乐 · 三平台

顶部切换网易云 / QQ 音乐 / 酷狗，手机号 / 扫码登录或粘贴 Cookie，共 20 个内容入口。

  • 网易云：每日推荐、我喜欢的、歌单、心动模式、收藏专辑、关注歌手、私人 FM、新碟、云盘
  • QQ 音乐：每日推荐、猜你喜欢、新歌、我喜欢的、歌单、推荐歌单
  • 酷狗：我喜欢的、我的歌单、推荐歌单

手机号 / 扫码登录

「我的音乐」不再只能按 F12 复制 Cookie。点「打开登录窗口（手机号 / 扫码）」，应用内用独立 session 打开官方登录页，输手机号 + 验证码或扫码，成功后自动读 Cookie 落库、窗口自动关闭。

  • 网易云：music.163.com/m/login，认 MUSIC_U
  • QQ 音乐：y.qq.com，认 qm_keyst / qqmusic_key
  • 酷狗：www.kugou.com，认 KuGoo / kg_music

云盘

两种网盘放在同一个页面：网易云音乐云盘，以及 WebDAV（坚果云等），可以浏览目录、点开即播。

本地音乐

多文件夹递归扫描 mp3 / flac / ape / wav / m4a 等，读取标签与时长并缓存；支持搜索、播放全部、收藏，列表里显示音质徽标。

一起听

与手机版同一协议、同一房间。

  • 房主权威 + 播放源机制，成员切歌后房间照样同步
  • 进度偏差自动校正、成员列表、转交房主、聊天
  • 「在浏览器打开网页版」：手机浏览器免装 App 直接加入

歌曲下载

播放栏与播放详情页都加了下载按钮，点开选音质；默认下载音质可记忆，文件命名、并发数、封面与歌词嵌入都在下载设置里。

平台设置

音源音质测试（逐档取链验证）、三平台账号状态、一起听中继与网页版地址、自定义主题背景、听歌播报（语速 + 试听）、关于与检查更新。

原有功能不动

搜索、歌单、排行榜、我的列表、下载、逐字歌词、桌面歌词、音效、音源脚本、深浅色主题全部保留，和上游 2.12.6 一致。

安装与使用

  1. 下载安装版，双击运行。若出现 SmartScreen 提示，点「更多信息」再点「仍要运行」。
  2. 安装完成后打开 LX Mod。想用「我的音乐」，点「打开登录窗口（手机号 / 扫码）」登录，或继续用粘贴 Cookie。
  3. 登录窗口是独立的持久 session，不影响系统浏览器与主窗口；退出登录会一并清掉它，下次打开不会直接是已登录状态。「粘贴 Cookie」保留在折叠区，登录窗打不开时仍可用。
  4. 想一起听：打开「一起听」，填昵称，创建房间，把 6 位房间码发给朋友，手机版也能进同一个房间。
  5. 导入音源脚本：设置 → 基本设置 → 音乐 API → 导入。导入后播放与下载才会按所选音质取链。
  6. 本地音乐：左侧「本地音乐」→ 添加文件夹，自动扫描。

常见问题

和手机版的数据互通吗？

不互通。电脑版是独立的桌面应用，歌单、设置、登录状态都存在本机。一起听房间是互通的，手机和电脑可以进同一个房间。

三平台怎么登录？还要手动复制 Cookie 吗？

1.1.3 起可以直接在应用内登录：点「打开登录窗口（手机号 / 扫码）」，用手机号 + 验证码或扫码，成功后自动读 Cookie 落库，窗口自动关闭。网易云认 MUSIC_U，QQ 认 qm_keyst，酷狗认 KuGoo。「粘贴 Cookie」仍保留在折叠区，登录窗打不开时可用；QQ / 酷狗进页面会自动点一次导航栏的「登录」。

云盘里的歌点了没声音？

网易云云盘的部分歌曲受版权限制，能否播放取决于账号权限和音源脚本。WebDAV 则是先下载到临时目录再播放，大文件首次打开会等几秒。

一起听连不上 / 一直重连？

默认用的是公网中继。如果所在网络屏蔽了 WebSocket，可以在「平台设置 → 一起听」里换成自建地址，例如 ws://192.168.1.10:23333，服务端见手机版仓库的 listen-together-server。

装完只有进程、没有窗口？

1.1.1 及更早的 Windows 版打包时带错了数据库原生模块（ABI 不匹配），数据库 worker 起不来，主进程就一直等。1.1.2 换成 N-API 预编译产物后已修复，覆盖安装即可。若仍打不开，启动时会弹窗写明原因和日志目录，不再静默卡死。

会覆盖我原来的洛雪吗？

不会。应用名是「LX Mod」，AppId 与官方不同，可以和官方版同时安装；但两者数据目录独立，歌单不共享。

11 档音质都能用吗？为什么选了没变化？

「能选、能按档位请求」和「音源真的返回该档位」是两回事。桌面版会按你选的档位向音源发起请求，失败后逐档回退；能否拿到 Master / Atmos / Hi-Res 取决于导入的音源脚本与账号权限。可在「平台设置 → 音源音质测试」里逐档验证。

怎么确认电脑版和手机版功能一致？

功能基线按手机版 v1.22.35 的功能清单逐项对齐；1.22.36 只修切歌报错，桌面版 1.1.3 则补上了手机号登录。1.22.32 ~ 1.22.36 的改动均为歌词定时器、逐字歌词时长、备份导入等缺陷修复。手机特有的系统能力（Android 锁屏 / 灵动岛歌词、背屏适配、系统 TTS 引擎）在桌面端由原生能力替代。
